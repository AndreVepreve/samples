# Glossary — Terms, Abbreviations, Concepts

> This glossary aggregates acronyms and terms discovered in the PDF. Known definitions are provided; others are left as entries for SME confirmation.

**ABAC** — Attribute-Based Access Control — authorization by user attributes/policies.
**ACL** — Access Control List — per-document or per-chunk permissions.
**ANN** — Approximate Nearest Neighbor — sub-linear vector search with accuracy/latency trade.
**HNSW** — Hierarchical Navigable Small World — an ANN index for fast vector similarity search.
**IVF** — Inverted File Index — coarse quantizer for partitioning vectors (FAISS).
**KNN** — k-Nearest Neighbors — find closest vectors by distance metric.
**KPI** — Key Performance Indicator — measurable outcome for success tracking.
**LLM** — Large Language Model — generative model trained on vast corpora for language tasks.
**OCR** — Optical Character Recognition — extract text from images or scanned documents.
**PQ** — Product Quantization — compress vectors for memory-efficient ANN search.
**RAG** — Retrieval-Augmented Generation — retrieve relevant context and generate grounded answers.
**RBAC** — Role-Based Access Control — authorization by user role.
**SLA** — Service Level Agreement — performance/availability commitments.
**SOP** — Standard Operating Procedure — formal instructions for operations.
