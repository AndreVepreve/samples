
# Comprehensive Glossary — 2025-09-09

ABAC — Attribute-Based Access Control.\
ACL — Access Control List.\
Agentic Framework — Autonomous AI orchestration and tools.\
AI Governance — Policies and controls for compliant AI.\
API — Application Programming Interface.\
ASL — Amazon States Language for Step Functions.\
AsyncAPI — Spec for event-driven APIs.\
Audit and Telemetry — Traces, logs, metrics for compliance and debugging.\
BPMN — Business Process Model and Notation.\
Blueprint — Declarative, versioned workflow artifact for AI document processing.\
Cedar — AWS fine-grained policy language.\
CI or CD — Continuous Integration or Continuous Deployment.\
Chunking — Splitting documents into smaller semantic units.\
Data Lake — Centralized storage for structured and unstructured data.\
Data Lineage — Traceability of data inputs to outputs.\
Decision Record — Auditable record of an execution and policies used.\
domusDocs — Angular plus NestJS plus Kubernetes document intelligence.\
DSL — Domain-Specific Language.\
Embeddings — Vector representations of text for semantic search.\
ETL — Extract Transform Load pipelines.\
Feature Store — Managed store for ML features.\
gRPC — High-performance RPC over HTTP2 with protobuf.\
Governance Layer — RBAC ABAC redaction lineage and HITL controls.\
GraphQL — Flexible query language for APIs.\
HITL — Human-in-the-Loop approvals.\
IaC — Infrastructure as Code.\
JSON Schema — Validation spec for JSON or YAML.\
KMS — Key Management Service for encryption and signing.\
LLM — Large Language Model.\
MCP Server — Model Control and Policy Server.\
Metadata Store — Aurora or DynamoDB holding document and blueprint metadata.\
OCI Artifacts — Portable, signed artifacts stored in container registries.\
Observability — OTEL traces, metrics, logs.\
OPA — Open Policy Agent policy engine.\
OpenAPI — REST API specification.\
OpenLineage — Open metadata standard for pipeline lineage.\
OTEL — OpenTelemetry instrumentation standard.\
PII — Personally Identifiable Information.\
Prompt Engineering — Techniques to control LLM behavior.\
RAG — Retrieval-Augmented Generation.\
RBAC — Role-Based Access Control.\
REST — Representational State Transfer.\
S3 — Amazon Simple Storage Service.\
SaaS — Software as a Service.\
Schema Validation — Enforcing artifact structure with JSON Schema.\
Self-Service AI — Business-configurable AI workflows.\
Semantic Search — Retrieval using embeddings or vectors.\
ServiceNow — ITSM platform used for tickets.create.\
Step Functions — AWS workflow service.\
Temporal — Open-source workflow engine.\
Tool Catalog — MCP-exposed registry of callable tools.\
Vector Database — OpenSearch, Pinecone, pgvector for embeddings.\
Workflow Artifact — Versioned YAML or JSON driving AI pipelines.
